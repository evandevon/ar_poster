# 3D models

Put .glb files here (keep them under about 10 MB). The editor finds them automatically:
add a "3D model" and pick one from the list. water-molecule.glb is a sample.

Tinkercad: Export → .GLTF (.glb). An .stl or .obj (3D printing) can be imported into
Tinkercad and exported again as .glb.
